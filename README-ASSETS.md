# Guide des visuels

Les SVG présents dans `public/images` sont des placeholders éditoriaux locaux. Pour la production, fournir aussi les variantes `.webp` demandées et remplacer :

- `hero-pen` : composition premium stylo + textile, cadrage large ;
- `recycled-textile` : textiles industriels pliés ou en vrac ;
- `textile-fibers` : macro de fibres ;
- `material-granules` : granulés issus de la transformation ;
- `injection-process` : environnement industriel propre, injection du corps ;
- `finished-pen` : stylo fini sur fond sobre ;
- `pen-detail` : photographie macro du toucher ;
- `pen-customization` : stylo marqué avec un logo fictif ;
- `europe-map.svg` : carte stylisée France–Italie.

Privilégier des fichiers WebP/AVIF nets, sans texte incorporé, avec droits d’usage documentés.
