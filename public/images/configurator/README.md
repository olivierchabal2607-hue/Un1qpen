# Images du configurateur

Les dix-huit vues nettoyées sont intégrées :

- `white-view1.png` à `white-view6.png`
- `warm-grey-view1.png` à `warm-grey-view6.png`
- `black-view1.png` à `black-view6.png`

Les six vues attendues sont, dans l’ordre : clip à gauche, clip et marquage,
face du clip, face opposée avec marquage, clip à droite, arrière sans clip.
Les trois couleurs sont utilisées par la rotation interactive actuelle.
